# MazeLab 迷宫寻路实验室

使用说明与项目交付说明 · Python 版 v1.1.0

## 一、项目简介

本项目面向计算机专业新生，通过可操作的迷宫网格展示 BFS、DFS 与 A* 的搜索过程。用户可以生成迷宫、手动画墙、设置起终点，并观察节点扩展与最终路径，理解数据结构、搜索策略和最短路径之间的联系。

本次交付为 Python + Tkinter 单文件实现，采用简洁的深色界面。安装包内嵌从同一份 Python 源码打包的程序，支持离线使用，无需账号。

## 二、安装与运行指南

### 安装包运行

双击 `turing_machine.exe`，按安装向导操作。程序安装到当前用户的 `%LOCALAPPDATA%\Programs\MazeLabCourse`，创建桌面及开始菜单快捷方式；安装本身无需管理员权限。

安装完成后，从桌面或开始菜单启动 MazeLab。卸载入口位于 Windows“设置 → 应用 → 已安装的应用”中的 MazeLab。

安装包面向 Windows 10/11 x64，内含 Python 与 Tcl/Tk 运行文件，无需另装 Python；当前实机验证环境为 Windows 11。安装包尚未进行代码签名。

### 源码运行

建议使用 Python 3.10 及以上，并确保发行版包含 tkinter/Tcl/Tk。本次在 Windows 11、Python 3.13 环境验证。源码运行无需安装第三方 Python 包。

```powershell
python turing_machine.py
python turing_machine.py --self-test
```

## 四、软件运行展示与验证

Python 版独立程序的运行窗口中，左侧为策略与地图编辑区，中间为迷宫网格，下方为动画控制和状态说明。左栏在小窗口下可使用滚动条查看。

源码自检通过 53,587 项断言，涵盖 120 张固定种子迷宫、三种算法的合法路径、BFS/A* 最短长度一致性、无解处理、中文文件路径读写及 4 类非法地图拒绝。安装包内嵌程序提取后，SHA-256 与打包后的 Python 程序一致。

已检查源码和独立程序的实际启动、单步及自动播放。完整安装/卸载生命周期与其他电脑的兼容性尚未实测；地图关闭后不自动保存，请主动保存。

## 五、主要功能说明

| 功能 | 操作与表现 |
| --- | --- |
| 迷宫生成 | 精巧 21×15、标准 31×21、宽阔 41×27 三档尺寸；随机回溯挖通通路，并加入少量环路。 |
| 地图编辑 | 支持画墙、橡皮、起点 S 和终点 E。左键拖动绘制，右键快速擦除；起终点不会重合或被墙覆盖。 |
| 搜索策略 | BFS 使用队列，DFS 使用栈，A* 使用最小堆与曼哈顿距离。所有移动均为上下左右四方向、每步代价为 1。 |
| 执行控制 | 支持开始、暂停、继续、单步和调速。Space 播放/暂停，N 单步，R 清除轨迹。 |
| 过程与对比 | 分别显示待探索、已探索、当前节点和最终路径；对比同一地图的探索节点数与路径步数。 |
| 地图文件 | 保存/导入 `.maze` 文本地图，检查尺寸、行长度、字符和起终点合法性。 |

N/R 字母快捷键请在英文输入状态使用，也可直接点击按钮。BFS 与本程序的 A* 保证等权网格中的最短路径；DFS 不保证最短。路径步数等于路径节点数减 1；算法计时不包含动画，单次数据仅供参考。
